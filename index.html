Extreme Parkour Demo Videos

Base teacher policy and distilled camera-based policy demos recorded under the same obstacle difficulty for direct comparison.

Demo Setup

Both policy demos were recorded with terrain difficulty 1.0 and camera observations enabled.

Terrain Difficulty 1.0
Observation Mode Camera enabled
Comparison Teacher vs. distilled policy

Base Teacher Policy

This demo shows the teacher base policy at iteration 7500. This checkpoint was saved before enabling delay, so it represents the non-delayed teacher policy used as the baseline for comparison.

Base Policy

Command

python base_play.py --headless --exptid base --proj_name parkour_new --use_camera --checkpoint 7500 --terrain_difficulty 1.0

Checkpoint

legged_gym/logs/parkour_new/base/model_7500.pt

Distilled Policy

This demo shows the distilled policy trained with camera input. The checkpoint used to generate this demo comes from the current depth-latent-loss branch. In this training setup, depth-latent loss is enabled and gradients are directly backpropagated through this loss during policy distillation.

Distilled Policy

Command

python distill_play.py --headless --exptid distill --proj_name parkour_new --use_camera --checkpoint 10000 --terrain_difficulty 1.0

Checkpoint

legged_gym/logs/parkour_new/distill/model_10000.pt

Comparison Notes

  • Both video groups use terrain difficulty 1.0, so the comparison is made under the same obstacle setting.
  • The base demo represents the teacher policy before delay is enabled.
  • The distill demo represents the camera-based student policy trained with direct gradient backpropagation from the depth-latent loss.
